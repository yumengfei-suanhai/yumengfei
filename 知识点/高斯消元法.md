# 高斯消元法
在科学、工程、经济学中，海量的问题最终都归结为求解一个线性方程组 $Ax = b$。例如：平衡一个复杂的化学反应，到为整个国家的经济制定生产计划，再到为互联网上的海量网页排序。高斯消元法正是求解这类问题的最基础、最通用的直接解法。以下介绍高斯消元法的相关内容。
## 一、高斯消元法的主要过程
### 示例：求解三元线性方程组
$$
\begin{cases}
x_1+x_2+x_3=3\\
2x_1+3x_2+4x_3=9\\
3x_1+6x_2+5x_3=14
\end{cases}
$$
该方程组包含3个未知数、3个方程。若直接求解，未知数求解顺序没有固定规律；但如果能把系数矩阵化为**上三角矩阵**，就能按照从下至上的固定顺序逐层求解、回代计算，流程清晰且计算简便。因此我们采用初等行变换，把方程组对应的增广矩阵化简为上三角形式：
$$
\left(\begin{array}{ccc|c}
1&1&1&3\\
2&3&4&9\\
3&6&5&14
\end{array}\right)
\xrightarrow[r_3-3r_1]{r_2-2r_1}
\left(\begin{array}{ccc|c}
1&1&1&3\\
0&1&2&3\\
0&3&2&5
\end{array}\right)
\xrightarrow{r_3-3r_2}
\left(\begin{array}{ccc|c}
1&1&1&3\\
0&1&2&3\\
0&0&-4&-4
\end{array}\right)
$$
变换后得到等价的上三角线性方程组：
$$
\begin{cases}
\begin{aligned}
x_1+x_2+x_3&=3\\
x_2+2x_3&=3\\
-4x_3&=-4
\end{aligned}
\end{cases}
$$
自最后一个方程向上依次计算：
1. 由 $-4x_3=-4$，解得 $x_3=1$；
2. 将 $x_3=1$ 代入第二个方程：$x_2=3-2x_3=1$；
3. 再将 $x_2=1,x_3=1$ 代入第一个方程：$x_1=3-x_2-x_3=1$。

综上，高斯消元法分为两大核心步骤：**前向消元**与**回代**。

- **前向消元**：利用初等行变换，将原方程组对应的增广矩阵化为等价的行阶梯形（上三角）矩阵。
- **回代**：对消元后得到的上三角方程组，从最后一行（最后一个方程）开始，自下而上逐层代入，解出全部未知量。

### （一）初等行变换
有三类初等行变换：
- 交换两行的位置
- 某行乘非零常数
- 某行的倍数加到另一行

    核心性质：初等行变换不改变矩阵的秩与方程组的解。
    
    所以经初等行变换得到的矩阵与原增广矩阵秩相等，经初等行变换得到的方程组与原方程组是同解方程组。

### （二）主元
主元就是每一步消元时，位于当前行当前列、用来“消灭”下方其他元素的那个“基准数”。

上述示例中，
```
第一步：主元是 (1,1) 位置的 1
第二步：主元是 (2,2) 位置的 1  
第三步：主元是 (3,3) 位置的 -4
```
>注意：主元不能为0，否则不能消去其他元素。

### （三）判断方程组解的情况
对增广矩阵做初等行变换化为行阶梯形后，可依据阶梯矩阵形态判定方程组解的三种情形：

- **无解**：若存在某一行形如 $\boldsymbol{(0\ \ 0\ \ \dots\ \ 0\mid c)}$，其中常数 $c\neq 0$，对应方程 $0x_1+0x_2+\dots+0x_n=c$，等式矛盾，方程组无解。

- **唯一解**：阶梯矩阵无矛盾行，且**主元个数 = 未知量总个数**，方程组存在唯一一组解。

- **无穷多解**：阶梯矩阵无矛盾行，且**主元个数 < 未知量总个数**，存在自由未知量，方程组有无穷多组解。

### （四）消元过程与回代过程的计算量
计算机硬件执行乘除法所需时钟周期远多于加减法，二者耗时差距显著。因此在数值算法复杂度分析领域有通用简化规则：仅统计乘除运算次数，加减法可直接忽略，该简化不会改变算法的渐近复杂度阶数。下文分析暂不处理主元为 0 的情形。

高斯消元法程序如下：
```python
import numpy as np
# 主元行循环
for i in range(n-1):
    # 下方所有待消元行
    for j in range(i+1,n): 
        l=A[j,i]/A[i,i] # 1 次除法
        A[j,i]=0
        A[j,i+1:n]-=l*A[i,i+1:n] # n-i-1 次乘法
        b[j]-=l*b[i] # 1 次乘法
```
回代过程程序如下：
```python
import numpy as np
# 从最后一行向上逐层求解
for i in range(n-1,-1,-1): 
    # 点积含 n-i-1 次乘法，末尾除以主元为 1 次除法
    x[i]=(b[i]-np.dot(A[i,i+1:n],x[i+1:n]))/A[i,i] 
```
高斯消元法过程中乘除法运算的次数为
$$\begin{aligned}
\sum_{i=0}^{n-2}\sum_{j=i+1}^{n-1}(n-i+1)&=\sum_{i=0}^{n-2}(n-i-1)(n-i+1)\\
&=\sum_{i=0}^{n-2}(n-i)^2-(n-1)\\
&\xlongequal{k=n-i}\sum_{k=2}^{n}k^2-n+1\\
&=\sum_{k=1}^{n}k^2-n\\
&=\frac{n(n+1)(2n+1)}{6}-n\\
&=\frac{n^3}{3}+\frac{n^2}{2}-\frac{5n}{6}
\end{aligned}$$

回代过程中乘除法运算的次数为
$$\begin{aligned}
\sum_{i=0}^{n-1}(n-i)\xlongequal{k=n-i}\sum_{k=1}^{n}k=\frac{n^2}{2}+\frac{n}{2}
\end{aligned}$$

综上，针对 $n$ 阶方阵对应的线性方程组，前向消元的计算复杂度为 $O(n^3)$，回代求解的计算复杂度为 $O(n^2)$。所以当未知量规模 $n$ 很大时，前向消元的三阶运算量会占据绝大部分计算开销。

## 二、高斯消元法面对的挑战
### （一）主元为零
主元用于消去当前列下方的其他元素，所以一定不能为 0，当主元为 0 时，我们将尝试选择新的主元。详细方法均在 “（三）主元选择策略” 中。
### （二）极小主元
计算机的精度有限，它使用浮点数来近似表示实数，这意味着计算过程中总是伴随着微小的舍入误差。

以下举一个例子来阐明一下极小主元的威胁

求解方程组
$$\begin{cases}
10^{-20}x_1+2x_2=1\\
x_1+x_2=1
\end{cases}$$
方程组的解为 $x_1=\frac{1}{2-10^{-20}},x_2=\frac{1-10^{-20}}{2-10^{-20}}$，不难看出两个数都非常接近 $\frac{1}{2}$
#### 1. 选择 $10^{-20}$ 作主元
$$\begin{pmatrix}
10^{-20}&2&|&1\\
1&1&|&1
\end{pmatrix}$$
第二行减去第一行的 $10^{20}$ 倍，得到
$$\begin{pmatrix}
10^{-20}&2&|&1\\
0&1-2\times10^{20}&|&1-10^{20}
\end{pmatrix}$$
然而计算机浮点数精度有限，双精度浮点数的十进制有效位数约为 15~16 位，$1-2\times10^{20}$ 与 $1-10^{20}$ 将舍入为 $-2\times10^{20}$ 与 $-10^{20}$，这就是 “大数吃小数”。
$$\begin{pmatrix}
10^{-20}&2&|&1\\
0&-2\times10^{20}&|&-10^{20}
\end{pmatrix}$$
回代计算得 $x_2=\frac{1}{2},x_1=0$

$x_2$ 的相对误差很小，而 $x_1$ 的相对误差是 $100\%$
#### 2. 交换一二行，选择 1 作主元
交换一、二行，得到
$$\begin{pmatrix}
1&1&|&1\\
10^{-20}&2&|&1\\
\end{pmatrix}$$
第二行减去第一行的 $10^{-20}$ 倍，得到
$$\begin{pmatrix}
1&1&|&1\\
0&2-10^{-20}&|&1-10^{-20}
\end{pmatrix}$$
$2-10^{-20}$ 与 $1-10^{-20}$ 将舍入为 2 与 1。
$$\begin{pmatrix}
1&1&|&1\\
0&2&|&1
\end{pmatrix}$$
回代计算得 $x_2=x_1=\frac{1}{2}$

此时 $x_2$ 与 $x_1$ 的相对误差都很小。

所以我们应当选择合适的主元来维持数值稳定性。

### （三）主元选择策略
以下介绍三种主元选择策略
### 部分主元选择
**在第 $k$ 步，选择使 $|a_{ik}|$ 最大的行 $i\geq k$ 作为主元，并将该行交换到第 $k$ 行。**

举个例子，
$$A=\begin{pmatrix}
1&1&1\\
2&3&4\\
3&6&5\\
\end{pmatrix}$$
第一步，第一列绝对值最大的元素为 3，在第三行。第一、三行交换，然后消去第一列下方的元素，得到
$$\begin{pmatrix}
3&6&5\\
2&3&4\\
1&1&1\\
\end{pmatrix}
\xrightarrow[r_3-\frac{1}{3}r_1]{r_2-\frac{2}{3}r_1}
\begin{pmatrix}
3&6&5\\
0&-1&\frac{2}{3}\\
0&-1&-\frac{2}{3}
\end{pmatrix}
$$
第二步，第二列（第二行及以下）绝对值最大的元素为 $-1$，在第二行。不必进行行交换，直接消去第二列下方的元素，得到
$$\begin{pmatrix}
3&6&5\\
0&-1&\frac{2}{3}\\
0&-1&-\frac{2}{3}
\end{pmatrix}
\xrightarrow{r_3-r_2}
\begin{pmatrix}
3&6&5\\
0&-1&\frac{2}{3}\\
0&0&-\frac{4}{3}
\end{pmatrix}$$
每一步所需的比较次数与 $n$ 成正比，总比较次数大约为 $\frac{n(n-1)}{2}$，这是一个 $O(n^2)$ 的复杂度。

### 完全主元选择
**在第 $k$ 步，不再局限于当前列，而是在右下角整个尚未处理的子矩阵中寻找绝对值最大的元素，然后同时交换行列，把它移到主元位置。**

举个例子，
$$A=\begin{pmatrix}
1&1&1\\
2&3&4\\
3&6&5\\
\end{pmatrix}$$
第一步，绝对值最大的元素是 6，在第三行第二列。第一、二列交换，第一、三行交换，然后消去第一列下方的元素，得到
$$
\begin{pmatrix}
6&3&5\\
3&2&4\\
1&1&1
\end{pmatrix}
\xrightarrow[r_3-\frac{1}{6}r_1]{r_2-\frac{1}{2}r_1}
\begin{pmatrix}
6&3&5\\
0&\frac{1}{2}&\frac{3}{2}\\
0&\frac{1}{2}&\frac{1}{6}
\end{pmatrix}$$
第二步，下方 $2\times2$ 的子矩阵中绝对值最大的元素是 $\frac{3}{2}$，在第二行第三列。第二、三列交换，然后消去第二列下方的元素，得到
$$\begin{pmatrix}
6&5&3\\
0&\frac{3}{2}&\frac{1}{2}\\
0&\frac{1}{6}&\frac{1}{2}
\end{pmatrix}
\xrightarrow{r_3-\frac{1}{9}r_2}
\begin{pmatrix}
6&5&3\\
0&\frac{3}{2}&\frac{1}{2}\\
0&0&\frac{4}{9}
\end{pmatrix}$$

完全主元选择较部分主元选择更加稳健，但是完全主元选择的总比较次数大约为 $\frac{n(n+1)(2n+1)}{6}-n$，这是一个 $O(n^3)$ 的复杂度，成本更高。因此，在实践中，我们几乎总是用部分主元选择。

### 缩放部分主元选择
首先计算比例因子向量 $s$，其元素为 $s_i = \max_{1 \leq j \leq n} |a_{ij}|$，然后在第 $k$ 步，使用与原始行相关联的固定比例因子 $s_i$，选择使 $\frac{|a_{ik}|}{s_i}$ 最大的行 $i \geq k$ 作为主元。
>注意：比例因子向量 $s$ 仅在分解前计算一次，其数值基于原始矩阵各行的最大绝对值，且后续行变换中 $s$ 的数值不变，但其分量随对应行的交换而同步交换位置。

举个例子，
$$A=\begin{pmatrix}
1&1&1\\
2&3&4\\
3&6&5\\
\end{pmatrix}$$
比例因子向量 $s=[1,4,6]$

第一步，$\frac{|a_{11}|}{s_1}=\frac{1}{1}=1,\frac{|a_{21}|}{s_2}=\frac{2}{4}=\frac{1}{2},\frac{|a_{31}|}{s_3}=\frac{3}{6}=\frac{1}{2}$，显然第一行符合要求。所以不用换，直接消去第一列下方的元素，得到
$$\begin{pmatrix}
1&1&1\\
2&3&4\\
3&6&5\\
\end{pmatrix}
\xrightarrow[r_3-3r_1]{r_2-2r_1}
\begin{pmatrix}
1&1&1\\
0&1&2\\
0&3&2
\end{pmatrix}
$$
第二步，$\frac{|a_{22}^{(1)}|}{s_2}=\frac{1}{4},\frac{|a_{32}^{(1)}|}{s_3}=\frac{3}{6}=\frac{1}{2}$，第三行符合要求。交换第二、三行，然后消去第二列的元素，得到
$$\begin{pmatrix}
1&1&1\\
0&3&2\\
0&1&2
\end{pmatrix}
\xrightarrow{r_3-\frac{1}{3}r_2}
\begin{pmatrix}
1&1&1\\
0&3&2\\
0&0&\frac{4}{3}
\end{pmatrix}$$

当方程组各行量级悬殊时（如“纳米” vs “光年”），部分主元选择会因系数绝对值的“虚假庞大”而误选主元。这种“大”源于单位尺度，而非数值重要性。缩放部分主元选择是部分主元选择的增强版，在保持 $O(n^2)$ 比较复杂度的同时，有效克服了尺度差异带来的误判，是实际计算中兼顾效率与稳定性的常用策略。
## 三、总结
以上便是高斯消元法的核心内容及其数值稳定性问题的基本处理方法。掌握了这些基础，我们将能够从容应对中小规模线性方程组的求解。然而，当问题规模达到成千上万乃至百万量级时，$O(n^3)$ 的复杂度将成为难以承受的负担——此时，迭代法将粉墨登场，成为求解大规模稀疏线性系统的主力军。而理解主元选择策略与误差传播规律，也正是进一步学习更复杂数值方法的起点。
